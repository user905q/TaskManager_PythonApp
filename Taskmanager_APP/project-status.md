## Для ВИ-14. Канбан-доска
В техническом задании предусмотрена возможность использования Канбан-доски для распределения задач.
В новой диаграмме вариантов использования присутствуют сценарии:
- Пользователь открывает вкладку Канбан-доски
- ViewModel запрашивает колонки из `board_columns`
- ViewModel запрашивает разделы и их задачи из `sections` и `tasks`
- View формирует доску: колонки + карточки разделов + задачи

В структурной диаграмме представлены основные элементы, необходимые для реализации данного сценария, в том числе сущности пользователя, колонки прогресса, раздела задач и задачи


##  Для ВИ-22. Управление колонками прогресса
В техническом задании предусмотрена возможность создания, переименования и удаления колонок прогресса.

В новой диаграмме вариантов использования присутствуют сценарии:
- Пользователь открывает диалог управления колонками
- Пользователь создаёт новую колонку
- Пользователь переименовывает существующую колонку
- Пользователь удаляет колонку

В структурной диаграмме представлены основные элементы, необходимые для реализации данного сценария, в том числе сущности пользователя, колонки прогресса и задачи

## ВИ-17. Автоматический расчёт прогресса
После добавления ВИ-14 потребовалось описать взаимосвязь колонок канбан-доски и расчёта прогресса.

В техническом задании предусмотрена возможность автоматического расчёта прогресса задачи при её перемещении между колонками Канбан-доски.

В новой диаграмме вариантов использования присутствуют сценарии:
Пользователь перетаскивает задачу в другую колонку
- View передаёт `moveTaskToColumn(taskId, columnId)` в `ViewModel`
- ViewModel вызывает `updateTaskColumn(taskId, columnId)` в `Model`
- Model обновляет `column_id` задачи в таблице tasks
- Model вызывает `calculateProgress(columnId)` для пересчёта прогресса
- Model обновляет `progress` задачи в таблице `tasks`
- ViewModel отправляет сигнал `progressChanged()`
- View обновляет прогресс-бар на карточке задачи

В структурной диаграмме представлены основные элементы, необходимые для реализации данного сценария, в том числе сущности пользователя, задачи, колонки прогресса и связи задачи с колонкой.
