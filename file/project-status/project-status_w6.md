**Отчёт по Этапу 3:** Реализован расширенный функционал. Создана двухзонная Канбан-доска (верхняя зона с глобальными колонками, нижняя — с карточками разделов). Создан модуль «Статистика» с круговой и столбчатой диаграммами (с переключением единиц измерения и фильтрами). Реализована вкладка «Лента» с безопасной фильтрацией. Настроена архивация и восстановление задач/разделов. Добавлены светлая и темная темы через QSS.
