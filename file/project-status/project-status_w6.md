## 4. Критерии проверки пользовательского сценария
Основной сценарий (создание задачи -> перемещение по Канбану -> архивация) выполняется полностью:
1. **Определены начальные условия:** чистая БД, запущенное приложение.
2. **Сценарий выполняется полностью:** без ручной подмены операций.
3. **Получен ожидаемый результат:** задача появляется, прогресс пересчитывается.
4. **Результат подтверждается:** данные сохраняются в `tasks.db` и `backups/`.
5. **Соблюдаются ограничения:** дедлайн не может быть в прошлом.
6. **Сценарий воспроизводим:** при повторном запуске данные сохраняются.
