## ВИ-1. Создание новой задачи

В техническом задании предусмотрена возможность создания задачи с указанием названия, раздела, тегов, дедлайна и вложений.
В новой диаграмме вариантов использования присутствуют сценарии:

- Пользователь нажимает кнопку «Новая задача»
- View открывает диалоговое окно `TaskDialog`
- Пользователь заполняет поля: название, описание, раздел, теги, дедлайн, прикрепляет файлы
- View передаёт данные в `TaskViewModel`
- ViewModel валидирует данные и вызывает `create()` в `TaskRepo`
- Model сохраняет задачу в таблице `tasks` (или в системном разделе, если раздел не указан)

В структурной диаграмме представлены основные элементы: сущности пользователя, задачи, раздела, тега, вложения и их связи.

## ВИ-17. Автоматический расчёт прогресса

В техническом задании предусмотрена возможность автоматического расчёта прогресса задачи при её перемещении между колонками.
В новой диаграмме вариантов использования присутствуют сценарии:

- Пользователь перетаскивает задачу в другую колонку
- View передаёт `moveTaskToColumn(taskId, columnId)` в `ViewModel`
- ViewModel вызывает `updateTaskColumn(taskId, columnId)` в `Model`
- Model обновляет `column_id` задачи в таблице `task_columns`
- Model вызывает `calculateProgress(columnId)` для пересчёта прогресса
- Model обновляет `progress` задачи в таблице `tasks`
- ViewModel отправляет сигнал `data_changed()`
- View обновляет прогресс-бар на карточке задачи

В структурной диаграмме представлены основные элементы: сущности пользователя, задачи, колонки прогресса и связи задачи с колонкой.

### Для ВИ-21. Прикрепление файла к задаче
1. Реализовать диалог выбора файла.
2. Реализовать копирование файла в папку `storage/` с уникальным именем.
3. Реализовать сохранение метаданных файла в таблицу `attachments`.
4. Реализовать отображение списка файлов на карточке задачи.

### Для ВИ-22. Управление колонками прогресса
1. Реализовать хранение данных о колонках прогресса.
2. Реализовать создание новой колонки.
3. Реализовать переименование существующей колонки.
4. Реализовать удаление колонки с переносом задач в первую колонку.
5. Реализовать получение списка колонок для отображения в диалоге.
6. Реализовать отображение актуального состояния колонок в пользовательском интерфейсе.


**Таким образом, требование технического задания сопоставляется с соответствующими UML-диаграммами и переводится в конкретные задачи реализации.**
