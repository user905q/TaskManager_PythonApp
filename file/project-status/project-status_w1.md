## 3. Ближайшие задачи

### Задача 1. Структура проекта + SQL

- Создать структуру пакетов: `app/db/`, `app/models/`, `app/viewmodels/`, `app/views/`, `app/views/dialogs/`, `app/views/widgets/`, `app/resources/styles/`, `app/resources/icons/`, `storage/`, `backups/`, `tests/`.
- Настроить `requirements.txt` (PyQt6, matplotlib, PyInstaller, pytest) — зафиксировать версии.
- Создать `app/db/schema.sql` — 10 таблиц (`sections`, `tasks`, `tags`, `task_tags`, `attachments`, `time_logs`, `board_columns`, `task_columns`, `notifications_log`, `settings`).
- Создать `app/db/migrations.py` — создание схемы при первом запуске + предустановленные данные (7 тегов, 3 колонки, системный раздел «Задачи без раздела»).
- Подготовить `schema.dbml`.
- Создать `main.py` (lock-файл `app.lock`, резервное копирование `tasks.db` в `backups/`, инициализация БД, запуск `QApplication`).
- Создать `app/config.py` и `app/logging_setup.py`.
- Создать репозиторий на GitHub (`.gitignore`, `README.md`).

### Задача 2. Слой Model

- `app/db/connection.py` — подключение к SQLite (WAL, `foreign_keys=ON`), декоратор `@transactional`, класс `DBError`.
- `app/models/entities.py` — dataclasses: `Task`, `Section`, `Tag`, `Attachment`, `TimeLog`, `BoardColumn`; класс `ValidationError`.
- `app/models/task_repo.py` — CRUD задач, валидация, архивирование/восстановление, привязка к системному разделу, ленивая выборка, автосортировка.
- `app/models/section_repo.py` — CRUD разделов, 2 стратегии удаления, защита системного раздела, расчёт прогресса раздела.
- `app/models/tag_repo.py` — справочник тегов, привязка/отвязка к задаче.
- `app/models/attachment_repo.py` — метаданные вложений, копирование в `storage/`, проверка свободного места.
- `app/models/timelog_repo.py` — автоматический таймер по смене колонки, агрегаты.
- `app/models/column_repo.py` — CRUD колонок, `recalc_progress_task` (math.ceil), `recalc_progress_section`, каскадный пересчёт.
- `app/models/archive_repo.py` — выборка архива, восстановление.
- `app/models/stats_repo.py` — агрегаты для «Статистики».
- `app/models/notification_repo.py` — проверка дедлайнов, `notifications_log`.
- `app/models/settings_repo.py` — key-value настройки.

### Задача 3. Слой ViewModel

- `app/viewmodels/base.py` — `BaseViewModel` (сигналы `changed`, `error`).
- `task_vm.py`, `section_vm.py` — CRUD задач и разделов.
- `board_vm.py` — две зоны Канбана: верх — колонки с задачами (DnD, автосортировка), низ — разделы с агрегированным прогрессом (сортировка: прогресс ↑ → `id`), ленивая подгрузка, пересчёт при изменениях.
- `feed_vm.py` — фильтры (дата, тег, статус, раздел, название), сортировка, ленивая подгрузка.
- `stats_vm.py` — 3 графика (pie / bar / line), метрики и периоды.
- `archive_vm.py` — загрузка и восстановление.
- `notification_vm.py` — `QTimer` (60 с) + `QSystemTrayIcon`.
- `settings_vm.py` — тема оформления.
- `main_vm.py` — координатор, ретрансляция сигналов во все вкладки.

### Задача 4. Слой View

- `app/views/main_window.py` — 4 вкладки + тулбар + меню + `QSystemTrayIcon` + «О программе».
- `board_tab.py` — `QSplitter` (верх `KanbanBoardZone`, низ `SectionsZone`).
- `widgets/kanban_board_zone.py`, `widgets/sections_zone.py`, `widgets/task_card.py`, `widgets/section_card.py`, `widgets/kanban_column.py`, `widgets/empty_state.py`.
- `feed_tab.py` — 6 фильтров + список + ленивая подгрузка.
- `stats_tab.py` — контролы + `FigureCanvas`, `safe_plot`.
- `archive_tab.py` — дерево + восстановление.
- Диалоги: `task_dialog.py` (вложения), `section_dialog.py`, `columns_dialog.py`, `confirm_dialog.py`, `about_dialog.py`.
- `app/resources/styles/light.qss`, `dark.qss`.

### Задача 5. Сборка и тестирование

- Сборка `.exe` через PyInstaller.
- Прогон 22 тест-сценариев из ТЗ (ВИ-1…ВИ-22).
- Pytest-тесты Model (`tests/`).
- Подготовка дистрибутива и CSV с тестовыми примерами.
- Документация (`README.md`, руководство пользователя).
